FiveStar Git Hooks
=

Install
===

- Upgrade your bash: `brew install bash`
- Clone githooks repo outside of your MedArrive directory `git clone https://github.com/fivestars/git-hooks.git ../git-hooks`
- Install git hooks as first class command: `../git-hooks/git-hooks install-command`
- Configure MedArrive as a FiveStar enabled repo: `git hooks install --no-preserve`
